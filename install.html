📱 Install on Android

  1. Recommended: tap Download the Android app above, open Nightwave.apk and allow installing.
  2. Or open this page in Chrome, tap Install Nightwave, then Install.
  3. No button? Tap Chrome's ⋮ menu → Add to Home screen → Install.

🍎 Install on iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button at the bottom.
  3. Scroll down and tap Add to Home Screen, then Add.

💻 Install on Windows or Mac

  1. Open this page in Chrome or Edge.
  2. Click Install Nightwave above — or the install icon at the right end of the address bar.
  3. Nightwave opens in its own window and appears in your Start menu / Applications.
