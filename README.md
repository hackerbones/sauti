# Sauti

Free music streaming web app with offline downloads, installable as a PWA.

- Streams full-length tracks from [Audius](https://audius.co) (free, artist-uploaded, no API key) — downloadable for offline
- Search and stream almost any song from YouTube via the official embedded player (needs your own free YouTube Data API key; stream only)
- Import your own music files or a whole folder for offline listening
- Artist profiles, follow artists with a new-releases feed, playlists
- Download tracks to play offline (stored in the browser), or import your own audio files
- Trending by genre, search, liked songs, queue, shuffle/repeat, media keys and lock-screen controls
- Installs to your phone or desktop home screen; the app itself works offline

Live: https://hackerbones.github.io/sauti/

**Install:** https://hackerbones.github.io/sauti/install.html
